Conventions that matter before reading anything else.
  • Money is an integer in minor units — paise for INR, cents for USD. Every column named *Amount, *Value, *Total, *Price, *Cost, *Duty, *Fee, *Tax or *Freight is flagged minor units below. Reading one as rupees is off by a hundred. The one exception is unitPrice*, a Float because component prices carry four decimals; it is converted to integer minor units at line level immediately so error cannot accumulate.
  • There are no native enums. SQLite has none, so enum-ish columns are String with the authoritative union types and Zod schemas in lib/domain/enums.ts. The comment on each such column lists the permitted values.
  • Provenance. Anything an external API could have produced carries provenance, provenanceActor, provenanceAt and provenanceRef, so a reader can always tell whether the platform was told a fact or assumed it.
  • Import IGST is not a cost. dutyIgst on WorkOrder is recoverable and is deliberately excluded from landed cost; dutyBcd and dutySws are real cost. Treating them alike misstates margin on every imported order.
  • Cascades are not uniform. Most children of WorkOrder cascade on delete. InputTaxCredit, ReverseChargeSelfInvoice and IntegrationCallLog hold a nullable workOrderId and do not cascade — deleting a work order would orphan tax rows into the registers, so they must be removed explicitly.

// ============================================================================
// 1BUY Fulfilment Platform — data model
// Master prompt §9. Postgres via Prisma (SQLite in earlier revisions).
//
// CONVENTIONS
//  * MONEY: every field named *Amount, *Value, *Total, *Price, *Cost, *Duty,
//    *Fee, *Tax, *Freight is an INTEGER in MINOR UNITS (paise for INR, cents
//    for USD). Never a float. The GST engine consumes and returns minor units
//    so rounding is explicit and testable (§11A.5a).
//    Exception: unitPrice* fields are Float, because component prices carry up
//    to 4 decimals. They are rounded to integer minor units at the line level
//    immediately, so float error never accumulates.
//  * ENUMS: enum-ish columns are String, with the authoritative union types +
//    Zod schemas in lib/domain/enums.ts. Kept as String rather than a native
//    Postgres enum because the permitted values change with business rules, and
//    a migration per value is a poor trade for a check the app already makes.
//  * PROVENANCE (§11A.0 rule 3): records that can be populated by an external
//    API carry provenance / provenanceActor / provenanceAt / provenanceRef.
// ============================================================================

generator client {
  provider = "prisma-client-js"
  /**
   * Generated INSIDE the project, not into node_modules.
   *
   * The dev server's file watcher does not cover node_modules, so a regenerated
   * client there stayed invisible until a full restart — every schema change
   * produced a "Unknown argument" crash on a field that genuinely existed.
   * Emitting here puts the client in the watched module graph, so it reloads.
   */
  output = "../lib/generated/prisma"
}
